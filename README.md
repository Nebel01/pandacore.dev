# Panda Software House

Sito statico HTML con Tailwind CSS via CDN.

## Struttura

- `index.html`: pagina principale
- `assets/css/style.css`: stili personalizzati
- `assets/js/main.js`: interazioni leggere
- `assets/img/`: immagini del sito

## Avvio

Non serve build.

Apri `index.html` nel browser oppure pubblica direttamente i file su GitHub Pages o su un hosting statico.
